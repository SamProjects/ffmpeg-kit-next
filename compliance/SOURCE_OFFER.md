# Corresponding Source Availability

The complete corresponding source used to build this FFmpegKitNext release is
available from the same GitHub Release page as the binary artifacts.

Download both:

- `ffmpeg-kit-next-source-<tag>.tar.gz` — the exact fork source, Android build
  scripts, GitHub Actions workflows, release-to-release patch, and reproduction
  instructions.
- `third-party-sources-<tag>.tar.gz` — the exact FFmpeg and linked third-party
  source revisions, including their license files and a resolved commit
  manifest.

Verify every downloaded file against `SHA256SUMS`. `BUILD_INFO.txt` records the
actual configure strings extracted from the published Android AARs.

The source assets will be kept available for at least as long as the
corresponding binaries remain available. Questions or source-access problems
may be reported through the repository's public GitHub issue tracker.

No fee is required to download the corresponding source. This availability
statement does not replace or reduce any rights granted by the applicable free
software licenses.
